Method 1: Browser Extension Recommended · Zero CLI

Use the lightweight browser extension to sync your logged-in muse.ai session directly into muse2api.
Why an extension is recommended: muse.ai's core cookies have the httpOnly flag, so page scripts (document.cookie) cannot read them, whereas the browser extension cookies API reads them directly.
1
Download and extract the extension
Extract the zip archive to a permanent folder on your computer.
⬇ Download muse2api-extension.zip
2
Load unpacked extension in Chrome / Edge / Brave
  1. Open chrome://extensions in your browser address bar
  2. Enable Developer mode in the top-right corner
  3. Click Load unpacked in the top-left corner
  4. Select the extracted folder from Step 1
3
Sign in to muse.ai and click the extension icon
Open https://muse.ai/ and sign in until the chat interface loads. Click the muse2api extension icon in your toolbar, paste the two values below, and click "Read & Import".

Method 2: Manual DevTools Copy Zero Install

You can also copy the cookie string from your browser's Network → Request Headers panel (which includes httpOnly cookies).
  1. Open and sign in to https://muse.ai/ until you see the chat UI
  2. Press F12 to open DevTools and switch to the Network tab
  3. Press F5 to reload the page
  4. Click any request to muse.ai in the list
  5. Under Headers → Request Headers, find the cookie: header
  6. Copy the entire value after cookie: (starting with hatch_sess=...)
  7. Paste it into Method 3 below and click Import

Integration Guide

Compatible with OpenAI and Anthropic SDKs — just set base_url and api_key.
BASE URL: —

1. Available Models

Model IDCapabilityEndpoint
muse-sparkChat / Code completion (streaming & non-streaming)POST /v1/chat/completions
POST /v1/responses
POST /v1/messages
muse-imageText-to-Image / Image EditingPOST /v1/images/generations
POST /v1/images/edits
muse-videoText-to-Video / Image-to-VideoPOST /v1/videos → GET /v1/videos/{id}
Common downstream model names (gpt-4o, claude-sonnet-4, dall-e-3, etc.) are automatically mapped to the corresponding Muse capability.

2. Chat Completions

Copy# Non-streaming
curl -X POST "BASE/v1/chat/completions" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"muse-spark","messages":[{"role":"user","content":"Write a quicksort in Go"}]}'

# Streaming: add "stream":true to receive standard SSE chunks

3. Image Generation (curl)

Copycurl -X POST "BASE/v1/images/generations" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"A Shiba Inu wearing an astronaut helmet","size":"1:1","response_format":"url"}'

4. Video Generation (curl, async)

Copy# ① Create task
curl -X POST "BASE/v1/videos" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"A kitten walking across a meadow","duration":5,"size":"16:9"}'

# ② Poll status
curl "BASE/v1/videos/task_xxx" -H "Authorization: Bearer $MUSE2API_KEY"
